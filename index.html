👋 What this is

A plain-language, dated record of the technical work done for Psanctuary, a sacred mushroom church, on GitHub (this organization is its decentralized, playful side), plus a /library of longer write-ups for anyone curious how it’s built. It’s written for someone outside the work who cares about it, not for the people already inside it.

The church’s real home is psanctuary.org. This is the quieter, technical side. This README is also the live site’s homepage.

🗂️ What’s here

  • changelog/: one markdown file per entry, named YYYY-MM-DD-short-slug.md.
  • library/: longer, standalone write-ups that don’t belong to one entry.
  • astro/: the Astro site itself.
  • ROADMAP.md and SUSTAINABILITY.md: where this is headed, and what keeps it running. Each is also a page on the site (/roadmap, /sustainability).
  • .github/workflows/sync-public.yml: on every push to main, builds the site and publishes only the finished pages (never this source) to psanctuary/changelog-astro-public.

Same pattern as the PIR® and Holy Earth Foundation changelogs.

✍️ Adding an entry

New file in changelog/, named YYYY-MM-DD-short-slug.md:

---
title: "Plain-language title"
date: "YYYY-MM-DD"
priority: "P2-medium" # P1-high, P2-medium (default), or P3-low
repo: "github" # which project card it belongs to
who: "Christopher W" # first name + last initial; see PEOPLE in astro/src/data/site.ts
---

Open with a one-line TL;DR, then put the full story inside a <details> block. If something can’t be described publicly (member details, ceremonies, legal matters), it doesn’t get an entry.
